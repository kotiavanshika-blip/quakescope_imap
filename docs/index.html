Grafana Dashboard for API Telemetry

QuakeScope

A small web API that serves recent earthquakes — watched live with Prometheus and Grafana. It measures request rate, latency and error rate, all started with one Docker command.

See the dashboard View source on GitHub

What it does

QuakeScope serves earthquake data from the USGS API, then counts and times every request it answers. Prometheus collects those numbers every 5 seconds and Grafana draws them — the classic RED method: Rate, Errors, Duration.

📈 Request rate

How busy the API is, in requests per second, overall and per endpoint.

⚠️ Error rate

The share of requests failing with a 5xx status, tracked over time.

⏱️ Latency

p50, p95 and p99 — because an average hides the slow requests.

How it fits together

A load generator sends steady traffic so the graphs are never empty. The API answers and publishes its numbers. Prometheus pulls those numbers; the API never pushes.

The path of one request

A client asks the API for something like /earthquakes/recent. A middleware sees it first and starts a stopwatch.
The API answers — reusing a saved copy for 60 seconds (a cache) or asking USGS. The middleware stops the clock and records the time and status code.
The API exposes these counters as plain text at /metrics.
Prometheus visits /metrics every 5 seconds (a scrape) and stores each value with a timestamp.
Grafana asks Prometheus for the numbers with PromQL and draws the dashboard.

The live website

A two-page site shows the same data as Grafana, plus buttons that break the API on purpose so you can watch the graphs react.

These are real captures from a test run with generated traffic. The graphs update live only when the full stack is running locally — see “Run it yourself” below.

Run it yourself

Everything starts with one command. You need Docker Desktop.

git clone https://github.com/kotiavanshika-blip/quakescope_IMAP_.git
cd quakescope_IMAP_
docker compose up -d --build

Then open, after about a minute:

AddressWhat you see
localhost:8081The website — start here, then open Live graphs
localhost:3000The Grafana dashboard (no login needed)
localhost:9090/targetsPrometheus — the API should say UP
localhost:8000/metricsThe raw numbers the API publishes
